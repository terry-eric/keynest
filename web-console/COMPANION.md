# 中文、多鍵組合與巨集

普通快捷鍵由 PCB2 的 USB HID 直接輸出，關閉控制台也能使用。文字、多個一般鍵的組合和多步巨集由桌面工具執行；動作保存在板子的 NVS，換電腦後不必重新設定，但每台電腦需要執行工具。

先將板子更新為 `macro-studio-v8` 或之後的巨集版韌體。舊版仍能使用普通快捷鍵，網站會標示需要更新。這份程式已編譯及完成主機測試，尚未完成實板或三個作業系統的輸入測試。

## 開始使用

電腦先安裝 Python，下載這個專案後，在專案目錄執行：

```text
python tools/start-companion.py --enable-input
```

瀏覽器開啟 `http://127.0.0.1:8029/pcb2/?companion=1`。工具和公開網站不能同時占用 USB；可在公開網站點「釋放 USB 並開啟桌面控制台」，或先中斷連接，再啟動工具。電腦保持原本 Wi-Fi。

點選一顆鍵，選擇「同時按多個鍵」「輸入一段文字」或「執行多步巨集」，完成後按「儲存到鍵盤」。切到想操作的程式，將游標放在文字欄，再按實體鍵。每次按下只執行一次；畫面上的「試燈光與聲音」不會輸入文字。

若只需要 Ctrl+C、Ctrl+Shift+S 這類修飾鍵加一個一般按鍵，選「送出快捷鍵」即可由鍵盤直接輸出，無需桌面工具。「同時按多個鍵」使用巨集執行器，即使內容是 Ctrl+C 也需要工具。

第一次會在專案內準備工具所需套件；之後沿用這個環境。停止工具：在執行工具的終端機按 Ctrl+C。若只要本機控制台而不允許文字輸入，省略 `--enable-input`；該模式不啟動巨集執行器。

## 各系統的條件

| 系統 | 輸入方式與條件 |
|---|---|
| Windows | 使用 pynput 的原生輸入；一般權限工具不能操作以系統管理員身分執行的程式。 |
| macOS | 使用 pynput／Quartz；需要在「隱私權與安全性 → 輔助使用」允許執行 Python 的程式。工具不代替使用者授予權限。 |
| Linux X11 | 需要正在執行的桌面工作階段，並有正確的 DISPLAY／X 權限。 |
| Linux Wayland | 安裝 `wtype`，且 compositor 需提供 virtual-keyboard 協定。沒有此協定時工具無法輸入，請使用 X11 工作階段；不能保證所有 GNOME／KDE Wayland 環境可用。 |

這些是已實作的後端及其必要條件，不代表已在各系統實測。特殊鍵依系統支援；執行前會先檢查整段巨集，遇到不支援的鍵就停止。快捷鍵大小寫與符號仍受電腦鍵盤配置影響。

巨集用 `META` 表示 Windows 的 Win 或 Mac 的 Command。組合可寫 `CTRL + SHIFT + A + B`，最多 16 個不同按鍵；亦支援 F1–F24、方向鍵與媒體鍵名稱。各後端不支援的鍵會被拒絕。

每顆鍵最多 16 步；每段文字最多 512 UTF-8 bytes、整段巨集最多 1200 bytes。等待每步 0–5000 毫秒，合計最多 30 秒。巨集會輸入到當時取得焦點的程式，不會自動尋找或切換應用程式。

## 斷線與失敗

「鍵盤 USB 被其他程式占用」表示公開網站或串列監控仍管理連線，先釋放它再回到本機控制台。重連成功後會清除 USB 錯誤；真正的輸入權限錯誤會保留到下一次成功執行。控制台顯示已收到、已執行和失敗次數，可區分板子事件與桌面輸出；「已送出」只表示輸入後端完成，仍需確認目標程式接受了操作。次數只記在工具的記憶體，重啟即歸零，不包含文字或巨集內容。

工具先確認並取走板子的動作事件，再輸入，避免 USB 回應不確定時重複打字。事件只有 2 秒有效期；工具斷線、沒有工具或上一段巨集仍在執行時，不排隊補送動作。失敗可能讓本次動作未執行或只執行一部分，請確認畫面後再按實體鍵；不會自動重試整段巨集。

工具不監聽整台電腦的鍵盤，不操作剪貼簿，不執行巨集內的命令或程式，也不記錄文字內容。它只監聽 localhost，核對 Host／Origin，網站不能直接要求它輸入任意文字；只有板子的實體按鍵事件會進入輸入執行器。

實作依據：[pynput 鍵盤 API](https://pynput.readthedocs.io/en/latest/keyboard.html)、[pynput 平台限制](https://pynput.readthedocs.io/en/latest/limitations.html)、[wtype 的 Unicode 與按鍵 API](https://github.com/atx/wtype)。
